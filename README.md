# Liquid Garden

An interactive artwork by [Wanli](https://wanlivisuals.com).

Flowers float in liquid light. Move your mouse (or drag on a phone) to send
waves through the water — the glitter drifts with the current. Choose a
flower from the menu.

Built with WebGL. All flower imagery generated by the artist with Adobe Firefly.

**Play:** https://melloww-w.github.io/liquid-garden/

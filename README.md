# 镜花水月

*Flowers in a mirror, moon in water* — an interactive artwork by [Wanli](https://wanlivisuals.com).

Move your cursor (or drag on a phone) to send waves through the water; the glitter
drifts with the current. Press **space** — or double-tap on a phone — for another flower.

Built with WebGL, no dependencies. All flower imagery generated by the artist with Adobe Firefly.

**Play:** https://melloww-w.github.io/liquid-garden/
